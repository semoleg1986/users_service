# Инварианты И Политики

## Бизнес-Инварианты

1. `UserProfile.user_id` уникален.
2. Переходы назначений ролей выполняются явно и аудируются.
3. `ParentStudentLink(parent_id, student_id)` уникален.
4. Для связи требуется роль `parent` с одной стороны и `student` с другой.
5. Архивный пользователь не может сохранять активные операционные связи.
6. Операции для blocked-пользователя ограничиваются политиками.

## Политики Доступа

- `AdminPolicy`: полный контур управления.
- `TeacherPolicy`: запись собственного профиля + разрешенные области чтения.
- `ParentPolicy`: запись собственного профиля + чтение связанных учеников.
- `StudentPolicy`: чтение/запись собственного профиля в рамках ограничений.

## Стратегия Применения

- инварианты в методах агрегатов
- permission checks в доменных политиках
- orchestration и межагрегатные проверки в application-хендлерах
- interface-слой только маппит ошибки в транспортный контракт
