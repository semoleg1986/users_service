# ADR-0001: Bounded Context Для Users Service

## Статус
Принято

## Дата
2026-04-05

## Контекст
Платформа состоит из независимых контекстов (`auth_service`, `users_service`, `course_service`).
Владение профилями и пользовательскими связями должно быть изолировано от auth и course логики.

## Решение
`users_service` владеет:
- жизненным циклом профиля пользователя
- жизненным циклом назначения ролей
- связями parent-student

`users_service` не владеет:
- аутентификацией и жизненным циклом токенов
- контентом и доставкой курсов
- orchestration уведомлений

Правило интеграции:
- взаимодействие только через API/events
- прямой доступ к БД внешними сервисами запрещен

## Последствия
- четкое владение user-доменом
- стабильные контракты для потребителей сервиса
- независимая эволюция и cadence релизов
